# Рекомендовані матеріали після завершення курсу

Це не обов’язковий список для читання «від першого до останнього пункту». Краще вибрати один основний матеріал, регулярно практикуватися і переходити до наступного тоді, коли з’явиться потреба. У добірці переважають практичні, візуальні та легко написані матеріали, доступні українською або російською мовою.

## Python: закріплення основ і практика

1. **[Python Essentials 1 — Cisco Networking Academy](https://www.netacad.com/courses/python-essentials-1)**  
   **Формат:** безплатний онлайн-курс. **Мова:** українська — її можна вибрати на платформі.  
   Послідовне повторення синтаксису Python, умов, циклів, функцій і базових структур даних. Хороший перший крок після курсу, якщо хочеться систематизувати знання та виконувати короткі перевірочні завдання.

2. **[«Автоматизация рутинных задач с помощью Python» — Ел Свейгарт](https://www.scribd.com/document/908948011/%D0%90%D0%B2%D1%82%D0%BE%D0%BC%D0%B0%D1%82%D0%B8%D0%B7%D0%B0%D1%86%D0%B8%D1%8F-%D0%A0%D1%83%D1%82%D0%B8%D0%BD%D0%BD%D1%8B%D1%85-%D0%97%D0%B0%D0%B4%D0%B0%D1%87-%D1%81-%D0%9F%D0%BE%D0%BC%D0%BE%D1%89%D1%8C%D1%8E-Python)**  
   **Формат:** книга. **Мова:** російський переклад.  
   Python пояснюється через корисні побутові сценарії: роботу з файлами, таблицями, текстом та автоматизацію повторюваних дій. Простий стиль і швидкий практичний результат добре підтримують інтерес.

3. **[«Изучаем Python: программирование игр, визуализация данных, веб-приложения» — Ерік Метіз](https://l-p.ua/wp-content/uploads/2021/10/metiz.-izuchaem-python.pdf)**  
   **Формат:** книга з вправами та проєктами. **Мова:** російський переклад.  
   Перша частина стисло закріплює базові поняття, а друга веде до більших проєктів: гри, візуалізації даних і вебзастосунку. Підійде тим, кому комфортно вчитися за одним структурованим підручником.

4. **[«Большая книга проектов Python» — Ел Свейгарт](https://flibusta.site/b/657688)**  
   **Формат:** книга з 81 невеликим проєктом. **Мова:** російський переклад.  
   Ігри, головоломки, симуляції та текстові програми, які можна запускати, змінювати й доповнювати. Особливо корисна, коли теорію вже зрозуміло, але бракує цікавих ідей для практики.

5. **[«Програмування для всіх: основи Python» — Prometheus](https://prometheus.org.ua/prometheus-free/python-fundamentals-for-everyone/)**  
   **Формат:** безплатний онлайн-курс. **Мова:** українська.  
   Українська версія курсу Чарльза Северанса з Університету Мічигану. Доступно пояснює основи Python і дає ще один спокійний маршрут для повторення матеріалу після курсу.

6. **[«Програмування для новачків» — Дія.Освіта](https://osvita.diia.gov.ua/courses/programming-for-beginners)**  
   **Формат:** безплатний освітній серіал. **Мова:** українська.  
   Короткі відео про алгоритми, мови програмування, принципи роботи комп’ютера та створення вебсторінок. Це легкий і цікавий огляд ширшої картини без складної теорії.

## Програмування та алгоритмічне мислення

7. **[«Грокаем алгоритмы», 2-ге видання — Адітья Бхаргава](https://fliphtml5.com/mynym/cgao/%D0%93%D1%80%D0%BE%D0%BA%D0%B0%D0%B5%D0%BC_%D0%B0%D0%BB%D0%B3%D0%BE%D1%80%D0%B8%D1%82%D0%BC%D1%8B_%28_PDFDrive_%29/)**  
   **Формат:** ілюстрована книга. **Мова:** російський переклад.  
   Дружнє знайомство з пошуком, сортуванням, хеш-таблицями, графами та оцінюванням швидкості алгоритмів. Багато малюнків і прикладів на Python роблять складні ідеї значно легшими для сприйняття.

## HTML і CSS

8. **[«Ваш перший вебсайт» — MDN Web Docs](https://developer.mozilla.org/ru/docs/Learn_web_development/Getting_started/Your_first_website)**  
    **Формат:** безплатний покроковий туторіал. **Мова:** російська.  
    Короткий маршрут від задуму до власної вебсторінки: структура HTML, оформлення CSS, трохи інтерактивності та публікація. Матеріал розрахований на початківців і одразу приводить до видимого результату.

9. **[Flexbox Froggy](https://flexboxfroggy.com/#uk)**  
    **Формат:** безплатна браузерна гра з 24 рівнями; можна обрати українську мову.  
    Веселий спосіб потренувати CSS Flexbox: потрібно переміщувати жабок на латаття за допомогою властивостей вирівнювання. Добре проходити після базового знайомства з HTML і CSS.

## Project management

10. **[«Deadline. Роман про управління проєктами» — Том ДеМарко](https://prom.ua/ua/m-6174412159022013441-deadline-roman-upravlenii.html?p=2422029451)**  
    **Формат:** книга-роман. **Мова:** російський переклад.  
    Історія про команди розробників, дедлайни, оцінювання строків і типові помилки керівників. Читається як художня книга, а наприкінці розділів залишає короткі практичні висновки.

11. **[«45 татуювань менеджера» — Максим Батирєв](https://prom.ua/ua/p2062319792-tatuirovok-menedzhera-maksim.html)**  
    **Формат:** книга, короткі самостійні розділи. **Мова:** російська.  
    Збірка конкретних управлінських історій і правил, побудована на досвіді автора. Її зручно читати невеликими частинами й обговорювати, з якими висновками ви погоджуєтеся, а з якими — ні.

## З чого почати

- Для впевненого повторення Python: **Python Essentials 1**, а потім один невеликий проєкт із **«Большой книги проектов Python»**.
- Для практичної користі в повсякденних задачах: **«Автоматизация рутинных задач с помощью Python»**.
- Для розвитку алгоритмічного мислення: **«Грокаем алгоритмы»**.
- Для першої вебсторінки: **«Ваш перший вебсайт»**, а після нього — **Flexbox Froggy**.
