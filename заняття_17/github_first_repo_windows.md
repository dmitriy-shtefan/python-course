# GitHub: реєстрація акаунта та створення першого репозиторію на Windows

## 1. Що таке GitHub

GitHub — це сайт, де зберігають код проєктів.

На GitHub можна:

- зберігати свої навчальні проєкти;
- показувати код викладачу або роботодавцю;
- працювати над проєктом з іншими людьми;
- бачити історію змін у файлах.

Репозиторій — це папка проєкту на GitHub. У репозиторії можуть бути файли з кодом, текстові файли, зображення та інші матеріали проєкту.

---

## 2. Попередні умови

Перед початком переконайтеся, що у вас є:

1. Компʼютер або ноутбук з Windows.
2. Доступ до інтернету.
3. Встановлений браузер: Google Chrome, Microsoft Edge, Firefox або інший.
4. Особиста електронна пошта, до якої ви маєте доступ.
5. Можливість відкрити лист від GitHub для підтвердження пошти.
6. Пароль, який ви зможете запамʼятати або зберегти у безпечному місці.

Рекомендації перед реєстрацією:

- використовуйте свою особисту пошту, а не тимчасову;
- не використовуйте один і той самий пароль для всіх сайтів;
- запишіть логін, пошту та пароль у надійне місце;
- не передавайте пароль іншим людям.

---

## 3. Як відкрити GitHub

1. Відкрийте браузер.
2. У верхньому рядку введіть адресу:

```text
github.com
```

3. Натисніть `Enter`.
4. Відкриється головна сторінка GitHub.

---

## 4. Як зареєструвати акаунт GitHub

### Крок 1. Почати реєстрацію

1. На головній сторінці GitHub знайдіть кнопку `Sign up`.
2. Натисніть `Sign up`.

`Sign up` означає «зареєструватися».

---

### Крок 2. Ввести електронну пошту

1. У поле для пошти введіть свою електронну адресу.
2. Перевірте, що адреса написана без помилок.
3. Натисніть кнопку для продовження.

Приклад пошти:

```text
student.name@gmail.com
```

Важливо: якщо в пошті буде помилка, ви не зможете підтвердити акаунт.

---

### Крок 3. Створити пароль

1. Придумайте пароль.
2. Введіть його у поле для пароля.
3. Натисніть кнопку для продовження.

Пароль має бути достатньо надійним.

Добрий пароль:

```text
Sun2026!Notebook
```

Поганий пароль:

```text
12345678
```

Не використовуйте приклади вище як свій справжній пароль.

---

### Крок 4. Створити імʼя користувача

GitHub попросить створити username.

Username — це ваше імʼя користувача на GitHub. Воно буде видно в адресі вашої сторінки.

Приклад:

```text
https://github.com/student-name
```

Поради для username:

- використовуйте латинські літери;
- можна використовувати цифри;
- можна використовувати дефіс `-`;
- не використовуйте пробіли;
- краще обрати коротке та зрозуміле імʼя.

Приклади:

```text
ivan-petrenko
anna-python
student2026
```

Якщо GitHub пише, що імʼя вже зайняте, додайте цифру або змініть імʼя.

---

### Крок 5. Підтвердити, що ви не робот

GitHub може показати перевірку.

Зазвичай потрібно:

1. Натиснути кнопку перевірки.
2. Виконати просте завдання на екрані.
3. Дочекатися завершення перевірки.

Це потрібно, щоб GitHub розумів, що акаунт створює людина.

---

### Крок 6. Підтвердити електронну пошту

1. Відкрийте свою пошту.
2. Знайдіть лист від GitHub.
3. Відкрийте лист.
4. Натисніть кнопку або посилання для підтвердження.

Якщо листа немає:

- перевірте папку `Spam` або `Спам`;
- перевірте папку `Promotions`, `Updates` або `Інші`;
- зачекайте кілька хвилин;
- перевірте, чи правильно введена пошта.

Після підтвердження пошти акаунт готовий до використання.

---

## 5. Як увійти в GitHub після реєстрації

1. Відкрийте сайт:

```text
github.com
```

2. Натисніть `Sign in`.
3. Введіть пошту або username.
4. Введіть пароль.
5. Натисніть кнопку входу.

`Sign in` означає «увійти».

---

## 6. Що таке репозиторій

Репозиторій — це місце для одного проєкту.

Наприклад, якщо ви створюєте навчальний проєкт `Hello Python`, для нього можна створити окремий репозиторій.

У репозиторії можуть бути:

- файли Python;
- HTML, CSS або JavaScript файли;
- текстові інструкції;
- зображення;
- файли з даними;
- опис проєкту.

Один репозиторій краще використовувати для одного проєкту.

---

## 7. Як створити перший репозиторій

### Крок 1. Відкрити сторінку створення репозиторію

1. Увійдіть у свій GitHub акаунт.
2. У правому верхньому куті знайдіть значок `+`.
3. Натисніть на нього.
4. Оберіть `New repository`.

`New repository` означає «новий репозиторій».

Також на головній сторінці GitHub може бути зелена кнопка `New`. Її теж можна використовувати для створення репозиторію.

---

### Крок 2. Ввести назву репозиторію

У полі `Repository name` введіть назву репозиторію.

Приклад:

```text
my-first-repository
```

Поради для назви:

- пишіть латинськими літерами;
- не використовуйте пробіли;
- замість пробілів використовуйте дефіс `-`;
- назва має коротко описувати проєкт.

Приклади хороших назв:

```text
python-homework
first-python-project
todo-app
html-css-practice
```

---

### Крок 3. Додати опис репозиторію

У полі `Description` можна коротко написати, для чого цей репозиторій.

Приклад:

```text
My first GitHub repository for learning Python.
```

Опис не обовʼязковий, але він допомагає швидко зрозуміти зміст проєкту.

---

### Крок 4. Обрати тип доступу

GitHub запропонує два варіанти:

```text
Public
Private
```

`Public` означає, що репозиторій буде видно іншим людям.

`Private` означає, що репозиторій буде видно тільки вам та людям, яким ви дасте доступ.

Для навчального першого репозиторію можна обрати `Public`, якщо там немає особистих даних, паролів або приватної інформації.

---

### Крок 5. Додати README файл

На сторінці створення репозиторію знайдіть опцію:

```text
Add a README file
```

Поставте галочку біля цієї опції.

README — це головний текстовий файл з описом проєкту. Він відкривається на головній сторінці репозиторію.

У README можна написати:

- назву проєкту;
- короткий опис;
- що вже зроблено;
- як запустити проєкт;
- що планується додати пізніше.

Для першого репозиторію краще створити README одразу.

---

### Крок 6. Не змінювати додаткові налаштування

На першому етапі можна не змінювати:

- `.gitignore`;
- `license`;
- інші додаткові параметри.

Ці налаштування можна вивчити пізніше.

---

### Крок 7. Створити репозиторій

1. Перевірте назву репозиторію.
2. Перевірте тип доступу: `Public` або `Private`.
3. Перевірте, що стоїть галочка `Add a README file`.
4. Натисніть кнопку `Create repository`.

Після цього GitHub відкриє сторінку нового репозиторію.

---

## 8. Як зрозуміти, що репозиторій створено правильно

Репозиторій створено правильно, якщо ви бачите:

1. Назву репозиторію у верхній частині сторінки.
2. Файл `README.md` у списку файлів.
3. Текст README на головній сторінці.
4. Адресу репозиторію в браузері.

Приклад адреси:

```text
https://github.com/your-username/my-first-repository
```

Де:

- `your-username` — ваше імʼя користувача;
- `my-first-repository` — назва вашого репозиторію.

---

## 9. Як додати перший текст у README

1. Відкрийте свій репозиторій.
2. Натисніть файл `README.md`.
3. Натисніть значок олівця або кнопку `Edit`.
4. Введіть текст.

Приклад тексту:

```markdown
# My First Repository

This is my first repository on GitHub.

I am learning how to use GitHub and store my projects online.
```

5. Прокрутіть сторінку вниз.
6. У полі для опису зміни можна написати:

```text
Update README
```

7. Натисніть кнопку `Commit changes`.

`Commit changes` означає «зберегти зміни в історії репозиторію».

---

## 10. Як створити новий файл у репозиторії

1. Відкрийте свій репозиторій.
2. Натисніть кнопку `Add file`.
3. Оберіть `Create new file`.
4. У полі назви файлу введіть:

```text
hello.txt
```

5. У велике поле введіть текст:

```text
Hello, GitHub!
```

6. Прокрутіть сторінку вниз.
7. У полі для опису зміни напишіть:

```text
Add hello file
```

8. Натисніть `Commit changes`.

Після цього файл зʼявиться у списку файлів репозиторію.

---

## 11. Як завантажити файл з компʼютера в репозиторій

1. Відкрийте свій репозиторій.
2. Натисніть `Add file`.
3. Оберіть `Upload files`.
4. Перетягніть файл з компʼютера у вікно браузера.

Або:

1. Натисніть `choose your files`.
2. Оберіть файл на компʼютері.
3. Натисніть `Open`.

Після вибору файлу:

1. Прокрутіть сторінку вниз.
2. У полі для опису зміни напишіть короткий текст.

Приклад:

```text
Upload homework file
```

3. Натисніть `Commit changes`.

Файл буде додано в репозиторій.

---

## 12. Що не треба додавати в публічний репозиторій

Не додавайте у публічний репозиторій:

- паролі;
- фото документів;
- номери банківських карток;
- приватні документи;
- особисті дані інших людей;
- файли з доступами до сайтів або сервісів;
- секретні ключі та токени.

Якщо файл містить приватну інформацію, не завантажуйте його на GitHub.

---

## 13. Часті проблеми

### Проблема: GitHub не приймає username

Можливі причини:

- таке імʼя вже зайняте;
- використані пробіли;
- використані недозволені символи.

Що зробити:

- змініть імʼя;
- додайте цифру;
- використайте дефіс `-`;
- пишіть латинськими літерами.

---

### Проблема: не приходить лист підтвердження

Що зробити:

- перевірте папку `Spam` або `Спам`;
- перевірте інші вкладки пошти;
- зачекайте кілька хвилин;
- перевірте правильність пошти;
- натисніть повторне надсилання листа, якщо така кнопка є.

---

### Проблема: не видно кнопку створення репозиторію

Що зробити:

- переконайтеся, що ви увійшли в акаунт;
- знайдіть значок `+` у правому верхньому куті;
- відкрийте меню біля свого аватара;
- знайдіть кнопку `New` або `New repository`.

---

### Проблема: випадково створено Private замість Public

Це можна змінити пізніше в налаштуваннях репозиторію.

Для навчання це не критична помилка. Private репозиторій просто не видно іншим людям без доступу.

---

## 14. Мінімальний результат після виконання інструкції

Після виконання всіх кроків у вас має бути:

1. Створений акаунт GitHub.
2. Підтверджена електронна пошта.
3. Створений перший репозиторій.
4. Доданий файл `README.md`.
5. Доданий файл `hello.txt` або інший тестовий файл.
6. Посилання на репозиторій.

Приклад посилання:

```text
https://github.com/your-username/my-first-repository
```

Це посилання можна надіслати викладачу.

---

## 15. Коротка памʼятка

1. Відкрити `github.com`.
2. Натиснути `Sign up`.
3. Ввести пошту, пароль і username.
4. Підтвердити пошту.
5. Увійти в GitHub.
6. Натиснути `+` або `New`.
7. Обрати `New repository`.
8. Ввести назву репозиторію.
9. Обрати `Public` або `Private`.
10. Поставити галочку `Add a README file`.
11. Натиснути `Create repository`.
12. Скопіювати посилання на репозиторій.
