# Git на Windows: встановлення, клонування репозиторію та перша зміна з компʼютера

Це інструкція для варіанту через `Git Bash`.

Якщо ви хочете працювати через PyCharm, не змішуйте ці кроки з PyCharm. Для PyCharm використовуйте окрему інструкцію:

```text
git_windows_pycharm_clone_first_change.md
```

У Git Bash ви вводите команди руками.

У PyCharm ті самі дії виконуються кнопками та меню.

---

## 1. Що таке Git

Git — це програма, яка допомагає зберігати історію змін у проєкті.

За допомогою Git можна:

- завантажити репозиторій з GitHub на свій компʼютер;
- змінювати файли проєкту локально;
- зберігати зміни в історії проєкту;
- відправляти зміни назад на GitHub;
- бачити, які файли були змінені.

GitHub — це сайт, де репозиторій зберігається онлайн.

Git — це програма на компʼютері, яка працює з репозиторієм.

Клонування репозиторію — це створення копії репозиторію з GitHub на вашому компʼютері.

---

## 2. Попередні умови

Перед початком переконайтеся, що у вас є:

1. Компʼютер або ноутбук з Windows.
2. Доступ до інтернету.
3. Встановлений браузер: Google Chrome, Microsoft Edge, Firefox або інший.
4. Створений акаунт GitHub.
5. Створений репозиторій на GitHub.
6. Доступ до цього репозиторію зі свого GitHub акаунта.

Якщо акаунта GitHub або репозиторію ще немає, спочатку виконайте інструкцію:

```text
github_first_repo_windows.md
```

## 3. Як завантажити Git для Windows

1. Відкрийте браузер.
2. У верхньому рядку введіть адресу:

```text
git-scm.com/download/win
```

3. Натисніть `Enter`.
4. Сторінка може автоматично почати завантаження інсталятора.
5. Якщо завантаження не почалося, знайдіть посилання для Windows installer.

Файл інсталятора може мати назву приблизно так:

```text
Git-2.xx.x-64-bit.exe
```

Числа у назві можуть бути іншими. Це нормально, бо версії Git оновлюються.

Важливо: завантажуйте Git з офіційного сайту:

```text
https://git-scm.com
```

---

## 4. Як встановити Git на Windows

### Крок 1. Запустити інсталятор

1. Відкрийте папку `Downloads` або `Завантаження`.
2. Знайдіть файл інсталятора Git.
3. Двічі натисніть на файл.
4. Якщо Windows запитає дозвіл на запуск, натисніть `Yes` або `Так`.

---

### Крок 2. Пройти встановлення

Під час встановлення Git буде показувати багато вікон з налаштуваннями.

Для першого встановлення можна залишати стандартні налаштування і натискати:

```text
Next
```

На останньому кроці натисніть:

```text
Install
```

Після завершення встановлення натисніть:

```text
Finish
```

Якщо під час встановлення є опція `Launch Git Bash`, її можна залишити увімкненою.

---

## 5. Як перевірити, що Git встановлено

1. Натисніть кнопку `Start` або клавішу `Windows`.
2. Почніть вводити:

```text
Git Bash
```

3. Відкрийте програму `Git Bash`.
4. У вікні Git Bash введіть команду:

```bash
git --version
```

5. Натисніть `Enter`.

Якщо Git встановлено правильно, ви побачите приблизно такий результат:

```text
git version 2.xx.x.windows.x
```

Числа можуть відрізнятися. Це нормально.

---

## 6. Як налаштувати своє імʼя та пошту в Git

Git має знати, хто робить зміни в репозиторії.

У Git Bash введіть команду зі своїм імʼям:

```bash
git config --global user.name "Your Name"
```

Приклад:

```bash
git config --global user.name "Ivan Petrenko"
```

Потім введіть команду зі своєю поштою:

```bash
git config --global user.email "your-email@example.com"
```

Приклад:

```bash
git config --global user.email "ivan.petrenko@gmail.com"
```

Краще використовувати ту саму пошту, з якою ви зареєструвалися на GitHub.

Щоб перевірити налаштування, введіть:

```bash
git config --global --list
```

Ви маєте побачити рядки приблизно такого вигляду:

```text
user.name=Ivan Petrenko
user.email=ivan.petrenko@gmail.com
```

## 7. Як скопіювати посилання на свій репозиторій

1. Відкрийте сайт:

```text
github.com
```

2. Увійдіть у свій акаунт.
3. Відкрийте свій репозиторій.
4. Натисніть зелену кнопку:

```text
Code
```

5. Переконайтеся, що обрано вкладку:

```text
HTTPS
```

6. Скопіюйте посилання.

Посилання буде виглядати приблизно так:

```text
https://github.com/your-username/my-first-repository.git
```

Де:

- `your-username` — ваше імʼя користувача GitHub;
- `my-first-repository` — назва вашого репозиторію.

---

## 8. Як обрати папку для проєктів на компʼютері

Перед клонуванням краще створити окрему папку для навчальних проєктів.

Наприклад:

```text
C:\Users\YourName\Documents\Projects
```

Або простіше:

```text
C:\Users\YourName\Desktop\Projects
```

У Git Bash папка `Desktop` записується так:

```bash
~/Desktop
```

Папка `Documents` записується так:

```bash
~/Documents
```

Щоб перейти на робочий стіл, введіть:

```bash
cd ~/Desktop
```

Щоб створити папку `Projects`, введіть:

```bash
mkdir Projects
```

Щоб перейти в цю папку, введіть:

```bash
cd Projects
```

---

## 9. Як клонувати репозиторій на компʼютер

У Git Bash перейдіть у папку, де хочете зберігати проєкти.

Наприклад:

```bash
cd ~/Desktop/Projects
```

Потім введіть команду `git clone` і вставте посилання на свій репозиторій:

```bash
git clone https://github.com/your-username/my-first-repository.git
```

Приклад:

```bash
git clone https://github.com/ivan-petrenko/my-first-repository.git
```

Після виконання команди Git створить нову папку з назвою репозиторію.

Щоб перейти в папку репозиторію, введіть:

```bash
cd my-first-repository
```

Назва папки має збігатися з назвою вашого репозиторію.

---

## 10. Як перевірити, що ви всередині репозиторію

У Git Bash введіть:

```bash
git status
```

Якщо все правильно, ви побачите повідомлення приблизно такого змісту:

```text
On branch main
Your branch is up to date with 'origin/main'.
nothing to commit, working tree clean
```

Це означає:

- ви всередині Git-репозиторію;
- зараз ви на гілці `main`;
- локальна копія збігається з GitHub;
- поки що немає нових змін.

---

## 11. Як відкрити папку репозиторію у VS Code

Якщо у вас встановлений Visual Studio Code, у папці репозиторію введіть:

```bash
code .
```

Крапка `.` означає «відкрити поточну папку».

Якщо команда `code .` не працює, можна відкрити VS Code вручну:

1. Запустіть Visual Studio Code.
2. Натисніть `File`.
3. Оберіть `Open Folder`.
4. Знайдіть папку свого репозиторію.
5. Натисніть `Select Folder`.

Також можна відкрити папку через Провідник Windows.

## 12. Як зробити першу зміну у файлі

Для першої зміни найзручніше змінити файл:

```text
README.md
```

1. Відкрийте файл `README.md`.
2. Додайте кілька рядків тексту.

Приклад:

```markdown
# My First Repository

This repository was cloned to my Windows computer.

I made my first local change using Git.
```

3. Збережіть файл.

У VS Code файл можна зберегти комбінацією клавіш:

```text
Ctrl + S
```

---

## 13. Як перевірити зміну через Git

Поверніться у Git Bash.

Переконайтеся, що ви в папці репозиторію.

Введіть:

```bash
git status
```

Git має показати, що файл `README.md` змінено.

Приблизний результат:

```text
Changes not staged for commit:
  modified: README.md
```

Це означає, що Git бачить зміну, але вона ще не збережена в історії.

---

## 14. Як підготувати зміну до коміту

Щоб додати файл до майбутнього коміту, введіть:

```bash
git add README.md
```

Після цього знову перевірте статус:

```bash
git status
```

Тепер Git має показати:

```text
Changes to be committed:
  modified: README.md
```

Це означає, що файл готовий до коміту.

---

## 15. Як зробити перший коміт

Коміт — це збережена точка в історії змін проєкту.

Щоб зробити коміт, введіть:

```bash
git commit -m "Update README from my computer"
```

Текст у лапках — це короткий опис зміни.

Приклади хороших описів коміту:

```text
Update README
Add first Python file
Fix homework task
Add project description
```

Після коміту зміна збережена на вашому компʼютері, але ще не відправлена на GitHub.

---

## 16. Як відправити зміну на GitHub

Щоб відправити коміт на GitHub, введіть:

```bash
git push
```

Або повну команду:

```bash
git push origin main
```

Під час першого `push` GitHub може попросити увійти в акаунт.

Можливі варіанти:

- відкриється вікно браузера для входу в GitHub;
- зʼявиться вікно Git Credential Manager;
- Git Bash попросить ввести логін або підтвердити код.

Увійдіть у той GitHub акаунт, де знаходиться ваш репозиторій.

Важливо: GitHub не приймає звичайний пароль акаунта як пароль у терміналі. Для першого разу зазвичай достатньо пройти вхід через браузер або Git Credential Manager.

---

## 17. Як перевірити зміну на GitHub

1. Відкрийте свій репозиторій на GitHub.
2. Оновіть сторінку.
3. Відкрийте файл `README.md`.
4. Перевірте, що ваш новий текст зʼявився на сайті.

Також на головній сторінці репозиторію має бути видно останній коміт.

Наприклад:

```text
Update README from my computer
```

Якщо зміна зʼявилася на GitHub, ви все зробили правильно.

---

## 18. Повний список команд для першої зміни

Нижче приклад повного шляху від клонування до відправлення зміни.

Замість посилання використайте посилання на свій репозиторій:

```bash
cd ~/Desktop
mkdir Projects
cd Projects
git clone https://github.com/your-username/my-first-repository.git
cd my-first-repository
git status
```

Після цього змініть файл `README.md` і збережіть його.

Потім виконайте:

```bash
git status
git add README.md
git commit -m "Update README from my computer"
git push
```

---

## 19. Що означають основні команди

Команда:

```bash
git clone
```

Створює копію репозиторію з GitHub на компʼютері.

Команда:

```bash
git status
```

Показує, які файли змінені.

Команда:

```bash
git add
```

Готує файл до коміту.

Команда:

```bash
git commit
```

Зберігає зміну в історії Git на вашому компʼютері.

Команда:

```bash
git push
```

Відправляє коміти з вашого компʼютера на GitHub.

## 20. Часті проблеми

### Проблема: команда `git` не знайдена

Можливий текст помилки:

```text
git: command not found
```

Або:

```text
'git' is not recognized as an internal or external command
```

Що зробити:

- перевірте, що Git встановлено;
- закрийте і знову відкрийте Git Bash;
- перезавантажте компʼютер;
- встановіть Git ще раз зі стандартними налаштуваннями.

---

### Проблема: не виходить вставити посилання в Git Bash

У Git Bash можна вставити текст так:

- натиснути праву кнопку миші;
- або натиснути `Shift + Insert`;
- або натиснути `Ctrl + Shift + V`.

Комбінація `Ctrl + V` може не працювати в деяких терміналах.

---

### Проблема: `Repository not found`

Можливий текст помилки:

```text
remote: Repository not found.
```

Можливі причини:

- посилання скопійоване з помилкою;
- репозиторій приватний, а ви не увійшли у правильний акаунт;
- репозиторій належить іншому користувачу;
- репозиторій було перейменовано або видалено.

Що зробити:

- відкрийте репозиторій у браузері;
- ще раз натисніть `Code`;
- скопіюйте HTTPS-посилання;
- спробуйте команду `git clone` ще раз.

---

### Проблема: папка вже існує

Можливий текст помилки:

```text
fatal: destination path 'my-first-repository' already exists
```

Це означає, що папка з такою назвою вже є на компʼютері.

Що зробити:

- перейдіть у вже створену папку:

```bash
cd my-first-repository
```

- або видаліть стару папку, якщо вона не потрібна;
- або клонуйте репозиторій в іншу папку.

---

### Проблема: Git не дає зробити коміт

Можливий текст помилки:

```text
Please tell me who you are.
```

Це означає, що не налаштовані імʼя та пошта.

Виконайте:

```bash
git config --global user.name "Your Name"
git config --global user.email "your-email@example.com"
```

Потім повторіть команду:

```bash
git commit -m "Update README from my computer"
```

---

### Проблема: `nothing to commit`

Можливий текст:

```text
nothing to commit, working tree clean
```

Це означає, що Git не бачить нових змін.

Що перевірити:

- чи справді ви змінили файл;
- чи зберегли файл після зміни;
- чи перебуваєте ви в правильній папці репозиторію;
- чи не зробили ви вже коміт раніше.

---

### Проблема: GitHub просить пароль у терміналі

GitHub більше не приймає звичайний пароль акаунта для роботи з Git через HTTPS.

Що зробити:

- якщо відкривається браузер, увійдіть через браузер;
- якщо зʼявляється Git Credential Manager, виконайте його інструкції;
- перевірте, що входите у правильний GitHub акаунт;
- якщо нічого не допомагає, попросіть викладача допомогти з авторизацією.

---

## 21. Мінімальний результат після виконання інструкції

Після виконання всіх кроків у вас має бути:

1. Встановлений Git на Windows.
2. Відкрита програма Git Bash.
3. Налаштовані `user.name` та `user.email`.
4. Скопійований репозиторій з GitHub на компʼютер.
5. Змінений файл `README.md`.
6. Зроблений перший локальний коміт.
7. Виконаний `git push`.
8. Зміна має бути видима на GitHub.

Приклад фінального результату на GitHub:

```text
README.md містить новий текст, який ви додали зі свого компʼютера.
```

Це означає, що ви навчилися робити повний цикл роботи:

```text
GitHub -> компʼютер -> зміна файлу -> commit -> push -> GitHub
```
