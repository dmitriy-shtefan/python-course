# Git на Windows через PyCharm: клонування репозиторію та перша зміна

Це інструкція для варіанту через PyCharm.

У цій інструкції не потрібно вводити команди `git clone`, `git add`, `git commit` або `git push` у Git Bash. PyCharm зробить ці дії через кнопки та меню.

Якщо ви хочете працювати через термінал і Git Bash, використовуйте іншу інструкцію:

```text
git_windows_clone_first_change.md
```

Не виконуйте обидві інструкції одночасно для одного й того самого першого кроку. Оберіть один варіант:

- Git Bash — якщо хочете вчитися працювати командами;
- PyCharm — якщо хочете працювати через графічний інтерфейс.

---

## 1. Що таке PyCharm у цій інструкції

PyCharm — це програма для написання коду Python.

У PyCharm можна:

- відкрити Python-проєкт;
- редагувати файли;
- запускати код;
- клонувати репозиторій з GitHub;
- робити commit;
- робити push на GitHub.

Git все одно має бути встановлений на компʼютері, але більшість дій ви будете виконувати не в Git Bash, а в PyCharm.

---

## 2. Попередні умови

Перед початком переконайтеся, що у вас є:

1. Компʼютер або ноутбук з Windows.
2. Доступ до інтернету.
3. Створений акаунт GitHub.
4. Створений репозиторій на GitHub.
5. Встановлений PyCharm.
6. Встановлений Git для Windows.

Якщо Git ще не встановлено, встановіть його з офіційного сайту:

```text
https://git-scm.com
```

Під час встановлення Git можна залишати стандартні налаштування.

---

## 3. Важливо: не плутайте Git Bash і PyCharm

У Git Bash робота виглядає так:

```text
git clone
git add
git commit
git push
```

У PyCharm замість цього ви використовуєте:

```text
Get from Version Control
Commit
Push
```

Для цієї інструкції використовуйте саме PyCharm.

Git Bash може знадобитися тільки для перевірки, що Git встановлений. Але клонування, commit і push у цій інструкції робимо через PyCharm.

---

## 4. Як перевірити Git у PyCharm

1. Відкрийте PyCharm.
2. Якщо відкрився якийсь проєкт, це нормально.
3. Відкрийте налаштування:

```text
File -> Settings
```

4. У лівому меню знайдіть:

```text
Version Control -> Git
```

5. Знайдіть поле:

```text
Path to Git executable
```

6. Натисніть кнопку `Test`, якщо вона є.

Якщо PyCharm показує версію Git, усе добре.

Якщо PyCharm не знаходить Git, спробуйте:

- встановити Git для Windows;
- перезапустити PyCharm;
- перезапустити компʼютер;
- повернутися в `File -> Settings -> Version Control -> Git` і знову натиснути `Test`.

---

## 5. Як увійти в GitHub через PyCharm

1. У PyCharm відкрийте:

```text
File -> Settings
```

2. У лівому меню знайдіть:

```text
Version Control -> GitHub
```

3. Натисніть кнопку `+` або `Add account`.
4. Оберіть вхід через GitHub.
5. PyCharm може відкрити браузер.
6. У браузері увійдіть у свій GitHub акаунт.
7. Дозвольте PyCharm доступ до GitHub, якщо GitHub це попросить.
8. Поверніться в PyCharm.

Якщо акаунт зʼявився у списку, PyCharm підключений до GitHub.

Якщо цього розділу немає або вхід не вийшов, можна все одно клонувати через HTTPS-посилання. Це описано далі.

---

## 6. Як скопіювати посилання на свій репозиторій

1. Відкрийте сайт:

```text
github.com
```

2. Увійдіть у свій акаунт.
3. Відкрийте свій репозиторій.
4. Натисніть зелену кнопку:

```text
Code
```

5. Оберіть вкладку:

```text
HTTPS
```

6. Скопіюйте посилання.

Посилання буде виглядати приблизно так:

```text
https://github.com/your-username/my-first-repository.git
```

---

## 7. Як клонувати репозиторій у PyCharm

### Варіант 1. Якщо PyCharm відкрив стартове вікно

1. Відкрийте PyCharm.
2. На стартовому екрані натисніть:

```text
Get from Version Control
```

3. У полі `URL` вставте посилання на репозиторій.
4. У полі `Directory` оберіть папку, куди зберегти проєкт.

Наприклад:

```text
C:\Users\YourName\Documents\Projects\my-first-repository
```

5. Натисніть:

```text
Clone
```

6. Якщо PyCharm запитає, чи довіряти проєкту, натисніть:

```text
Trust Project
```

---

### Варіант 2. Якщо у PyCharm вже відкритий інший проєкт

1. У верхньому меню відкрийте:

```text
File -> New -> Project from Version Control
```

Або:

```text
Git -> Clone
```

2. У поле `URL` вставте посилання на репозиторій.
3. У полі `Directory` оберіть папку для проєкту.
4. Натисніть:

```text
Clone
```

5. Якщо PyCharm запитає, чи відкрити проєкт у новому вікні, можна обрати:

```text
New Window
```

Так легше не переплутати різні проєкти.

---

## 8. Як зрозуміти, що репозиторій клоновано правильно

Репозиторій клоновано правильно, якщо:

1. У PyCharm відкрилася папка вашого проєкту.
2. Зліва видно список файлів.
3. Серед файлів є `README.md`.
4. У верхньому меню є пункт `Git`.
5. PyCharm не показує помилку про відсутній Git.

Якщо файл `README.md` видно в PyCharm, можна переходити до першої зміни.

---

## 9. Як зробити першу зміну у файлі

1. У лівій панелі PyCharm знайдіть файл:

```text
README.md
```

2. Відкрийте його подвійним кліком.
3. Додайте кілька рядків тексту.

Приклад:

```markdown
# My First Repository

This repository was cloned to my Windows computer using PyCharm.

I made my first local change in PyCharm.
```

4. Збережіть файл:

```text
Ctrl + S
```

PyCharm також може зберігати файли автоматично, але для першого разу краще натиснути `Ctrl + S`.

---

## 10. Як побачити зміну в PyCharm

Після зміни файлу PyCharm зазвичай підсвічує його в списку файлів.

Файл може змінити колір або отримати позначку біля назви.

Так PyCharm показує, що файл відрізняється від версії, яка була в останньому commit.

Щоб подивитися зміни:

1. Відкрийте файл `README.md`.
2. Знайдіть кольорові позначки біля лівого краю редактора.
3. Або відкрийте вкладку `Commit`, якщо вона є зліва.

---

## 11. Як зробити commit у PyCharm

Commit — це збережена точка в історії змін проєкту.

1. Відкрийте вікно commit:

```text
Git -> Commit
```

Або натисніть:

```text
Ctrl + K
```

2. У списку змінених файлів знайдіть `README.md`.
3. Переконайтеся, що біля `README.md` стоїть галочка.
4. У поле повідомлення commit введіть короткий опис зміни.

Приклад:

```text
Update README from PyCharm
```

5. Натисніть кнопку:

```text
Commit
```

Після цього зміна збережена в історії Git на вашому компʼютері.

Важливо: після `Commit` зміна ще не обовʼязково є на GitHub. Щоб відправити її на GitHub, потрібно зробити `Push`.

---

## 12. Як зробити push у PyCharm

Push — це відправлення ваших commit з компʼютера на GitHub.

1. У верхньому меню відкрийте:

```text
Git -> Push
```

Або натисніть:

```text
Ctrl + Shift + K
```

2. Відкриється вікно `Push Commits`.
3. Перевірте, що там є ваш commit.

Наприклад:

```text
Update README from PyCharm
```

4. Натисніть:

```text
Push
```

Якщо PyCharm попросить увійти в GitHub, увійдіть у той акаунт, де знаходиться ваш репозиторій.

---

## 13. Як перевірити зміну на GitHub

1. Відкрийте свій репозиторій на GitHub.
2. Оновіть сторінку.
3. Відкрийте файл:

```text
README.md
```

4. Перевірте, що текст, який ви додали в PyCharm, зʼявився на GitHub.

Якщо текст зʼявився на GitHub, ви все зробили правильно.

---

## 14. Що у PyCharm відповідає командам Git Bash

Цю таблицю не потрібно виконувати. Вона тільки пояснює відповідність.

| Дія | У Git Bash | У PyCharm |
| --- | --- | --- |
| Клонувати репозиторій | `git clone ...` | `Get from Version Control` або `Git -> Clone` |
| Подивитися змінені файли | `git status` | вкладка `Commit`, підсвічені файли |
| Підготувати файл до commit | `git add README.md` | галочка біля файлу у вікні `Commit` |
| Зберегти зміну в історії | `git commit -m "..."` | кнопка `Commit` |
| Відправити зміну на GitHub | `git push` | `Git -> Push` або `Ctrl + Shift + K` |

Якщо ви працюєте через PyCharm, не треба окремо вводити ці команди в Git Bash.

---

## 15. Часті проблеми

### Проблема: PyCharm не бачить Git

Можлива причина: Git не встановлено або PyCharm не знає, де він знаходиться.

Що зробити:

- встановіть Git для Windows з `https://git-scm.com`;
- перезапустіть PyCharm;
- відкрийте `File -> Settings -> Version Control -> Git`;
- натисніть `Test`.

---

### Проблема: не видно `Get from Version Control`

Що зробити:

- якщо ви на стартовому екрані PyCharm, шукайте кнопку `Get from Version Control`;
- якщо вже відкритий проєкт, використайте `File -> New -> Project from Version Control`;
- також можна використати `Git -> Clone`.

---

### Проблема: `Repository not found`

Можливі причини:

- посилання на репозиторій скопійоване з помилкою;
- ви увійшли не в той GitHub акаунт;
- репозиторій приватний;
- у вас немає доступу до репозиторію.

Що зробити:

- відкрийте репозиторій у браузері;
- ще раз натисніть `Code`;
- скопіюйте HTTPS-посилання;
- перевірте, що ви увійшли у правильний GitHub акаунт;
- повторіть клонування в PyCharm.

---

### Проблема: PyCharm просить логін GitHub

Це нормально під час першого clone або push.

Що зробити:

- увійдіть у свій GitHub акаунт;
- якщо відкрився браузер, підтвердьте вхід у браузері;
- якщо PyCharm просить дозвіл для GitHub, підтвердьте його;
- після входу поверніться в PyCharm.

---

### Проблема: кнопка `Commit` неактивна

Можливі причини:

- файл не змінено;
- файл не збережено;
- не стоїть галочка біля файлу;
- не написано повідомлення commit.

Що зробити:

- змініть файл `README.md`;
- натисніть `Ctrl + S`;
- відкрийте `Git -> Commit`;
- поставте галочку біля `README.md`;
- напишіть повідомлення commit.

---

### Проблема: зміна є в PyCharm, але її немає на GitHub

Можлива причина: ви зробили `Commit`, але не зробили `Push`.

Що зробити:

1. У PyCharm відкрийте:

```text
Git -> Push
```

2. Натисніть:

```text
Push
```

3. Оновіть сторінку репозиторію на GitHub.

---

## 16. Мінімальний результат після виконання інструкції

Після виконання всіх кроків у вас має бути:

1. Встановлений Git.
2. Встановлений PyCharm.
3. Репозиторій з GitHub відкритий у PyCharm.
4. Змінений файл `README.md`.
5. Зроблений commit у PyCharm.
6. Зроблений push у PyCharm.
7. Зміна видима на GitHub.

Фінальний цикл роботи виглядає так:

```text
GitHub -> PyCharm -> зміна файлу -> Commit -> Push -> GitHub
```
