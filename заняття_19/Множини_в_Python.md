# Множини в Python

## 1. Що таке множина

Множина, або `set`, - це колекція унікальних значень.

Якщо додати в множину однакові елементи, Python залишить тільки один екземпляр.

```python
cities = {"Київ", "Львів", "Київ", "Одеса"}
print(cities)
```

У результаті `Київ` буде тільки один раз.

Важливо: порядок елементів у множині не головний. Якщо потрібен стабільний порядок, використовують `sorted()`.

## 2. Як створити множину

Множину можна створити фігурними дужками:

```python
tags = {"python", "web", "streamlit"}
```

Або зі списку:

```python
cities = ["Київ", "Львів", "Київ", "Одеса"]
unique_cities = set(cities)
print(unique_cities)
```

Це зручно, коли потрібно прибрати дублікати.

## 3. Основні дії

Додати елемент:

```python
tags = set()
tags.add("python")
tags.add("web")
print(tags)
```

Перевірити, чи є елемент:

```python
allowed_cities = {"Київ", "Львів", "Одеса"}

if "Київ" in allowed_cities:
    print("Місто доступне")
```

Отримати унікальні значення у зручному порядку:

```python
cities = ["Київ", "Львів", "Київ", "Одеса"]
unique_cities = sorted(set(cities))
print(unique_cities)
```

## 4. Приклади застосування

Множини зручно використовувати як інструмент для фільтрів.

Наприклад, якщо в контактах багато людей з однакових міст, можна отримати список унікальних міст:

```python
contacts = [
    {"name": "Оля", "city": "Київ"},
    {"name": "Іван", "city": "Львів"},
    {"name": "Аліна", "city": "Київ"}
]

cities = []

for contact in contacts:
    cities.append(contact["city"])

unique_cities = sorted(set(cities))
print(unique_cities)
```

Результат:

```python
["Київ", "Львів"]
```

Такий список можна використати для фільтра за містом у програмі.

- `Львів`
- `Одеса`

Є список:

```python
cities = ["Київ", "Львів", "Київ", "Одеса", "Львів", "Дніпро"]
```

Створи змінну `unique_cities`, у якій будуть тільки унікальні міста.

Виведи:

- початковий список;
- множину з унікальними містами.

## Завдання 3. Унікальні міста в алфавітному порядку

Використай список із завдання 2.

Створи змінну `sorted_cities`, де міста будуть без дублікатів і в алфавітному порядку.

Підказка:

```python
sorted_cities = sorted(set(cities))
```

Виведи результат.

## Завдання 4. Перевірка міста

Є множина:

allowed_cities = {"Київ", "Львів", "Одеса"}

## Завдання 5. Унікальні міста з контактів

Є список контактів:

```python
contacts = [
    {"name": "Оля", "phone": "0991112233", "city": "Київ"},
    {"name": "Іван", "phone": "0672223344", "city": "Львів"},
    {"name": "Аліна", "phone": "0503334455", "city": "Київ"},
    {"name": "Максим", "phone": "0634445566", "city": "Одеса"}
]
```

Створи список `cities`.

Через цикл `for` додай у нього місто кожного контакту.

Потім створи:

```python
unique_cities = sorted(set(cities))
```

Виведи список унікальних міст.

Очікуваний результат:

```python
["Київ", "Львів", "Одеса"]
```

## Міні-підсумок

Запам'ятай:

- `set` зберігає тільки унікальні значення;
- `set(list)` прибирає дублікати зі списку;
- `.add()` додає елемент у множину;
- `in` перевіряє наявність елемента;
- `sorted(set(...))` дає унікальні значення у зручному порядку.
