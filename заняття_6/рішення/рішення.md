# Підготовчі завдання: навіщо потрібні списки

Ці завдання можна виконати без списків через окремі змінні. Але зі списками рішення стає коротшим, зрозумілішим і легше розширюється.

## Підготовче завдання 1. Студенти групи

Інструкція: задати студентів групи вручну в коді, без `input`, і вивести їх. Без списку це можна зробити через окремі змінні; зі списком усі студенти зберігаються в одній змінній.

Приклад вводу/виводу:

```text
Ввід: немає

Вивід:
Студенти: ['Оля', 'Максим', 'Ірина']
```

Рішення без списку:

```python
student1 = "Оля"
student2 = "Максим"
student3 = "Ірина"

print("Студенти:", student1, student2, student3)
```

Рішення зі списком:

```python
students = ["Оля", "Максим", "Ірина"]

print("Студенти:", students)
```

## Підготовче завдання 2. Перевірка дозволеної команди

Інструкція: користувач вводить команду. Дозволені команди: `start`, `help`, `exit`. Програма має перевірити, чи команда дозволена. Без списку доведеться писати кілька порівнянь через `or`; зі списком можна використати `in`.

Приклад вводу/виводу:

```text
Ввід:
help

Вивід:
Команда дозволена
```

Рішення без списку:

```python
command = input("Команда: ").strip().lower()

if command == "start" or command == "help" or command == "exit":
    print("Команда дозволена")
else:
    print("Невідома команда")
```

Рішення зі списком:

```python
allowed_commands = ["start", "help", "exit"]
command = input("Команда: ").strip().lower()

if command in allowed_commands:
    print("Команда дозволена")
else:
    print("Невідома команда")
```

## Підготовче завдання 3. Вибір студента за номером

Інструкція: є три студенти: Оля, Максим, Ірина. Користувач вводить номер від 1 до 3. Програма має вивести ім'я студента. Без списку це можна зробити через `if/elif`; зі списком достатньо перетворити номер на індекс.

Приклад вводу/виводу:

```text

2

Вивід:
Студент: Максим
```

Рішення без списку:

```python

student3 = "Ірина"

number = int(input("Номер студента: "))

if number == 1:
    print("Студент:", student1)
elif number == 2:
    print("Студент:", student2)
elif number == 3:
    print("Студент:", student3)
else:
    print("Некоректний номер")
```

Рішення зі списком:

```python
students = ["Оля", "Максим", "Ірина"]

    print("Студент:", students[index])
else:
    print("Некоректний номер")
```

## Підготовче завдання 5. Видалення останнього повідомлення

Інструкція: є три повідомлення. Потрібно видалити останнє і показати ті, що залишились. Без списку доводиться просто не виводити одну зі змінних; зі списком можна реально прибрати елемент через `pop`.

Приклад вводу/виводу:

```text
Ввід: немає

Вивід:
Видалено: третє повідомлення
['перше повідомлення', 'друге повідомлення']
```

Рішення без списку:

```python
message1 = "перше повідомлення"
message2 = "друге повідомлення"
message3 = "третє повідомлення"

print("Видалено:", message3)
print(message1, message2)
```

Рішення зі списком:

```python
messages = ["перше повідомлення", "друге повідомлення", "третє повідомлення"]

deleted_message = messages.pop()

print("Видалено:", deleted_message)
print(messages)
```

## Вправа 16. Просте меню списку покупок

Інструкція: програма має працювати до команди `0`. Команда `1` додає товар до списку, команда `2` показує весь список, команда `3` показує кількість товарів.

Приклад вводу/виводу:

```text
Ввід:
1
молоко
1
хліб
2
3
0

Вивід:
Товар додано
Товар додано
['молоко', 'хліб']
Кількість товарів: 2
Програму завершено
```

Рішення:

```python
products = []
command = ""

while command != "0":
    print("1 - додати товар")
    print("2 - показати список")
    print("3 - показати кількість")
    print("0 - вихід")

    command = input("Ваш вибір: ").strip()

    if command == "1":
        product = input("Товар: ").strip().lower()

        if product:
            products.append(product)
            print("Товар додано")
        else:
            print("Назва товару порожня")
    elif command == "2":
        print(products)
    elif command == "3":
        print("Кількість товарів:", len(products))
    elif command == "0":
        print("Програму завершено")
    else:
        print("Невідома команда")
```

## Вправа 20. Меню контактів

Інструкція: програма має працювати до команди `0`. Команда `1` додає ім'я контакту до списку, команда `2` показує список контактів, команда `3` перевіряє, чи є контакт у списку, команда `4` видаляє контакт.

Приклад вводу/виводу:

```text
Ввід:
1
Оля
1
Максим
3
оля
4
максим
2
0

Вивід:
Контакт додано
Контакт додано
Контакт знайдено
Контакт видалено
['оля']
Контакти закрито
```

Рішення:

```python
contacts = []
command = ""

while command != "0":
    print("1 - додати контакт")
    print("2 - показати контакти")
    print("3 - знайти контакт")
    print("4 - видалити контакт")
    print("0 - вихід")

    command = input("Ваш вибір: ").strip()

    if command == "1":
        contact = input("Ім'я контакту: ").strip().lower()

        if contact:
            contacts.append(contact)
            print("Контакт додано")
        else:
            print("Ім'я порожнє")
    elif command == "2":
        print(contacts)
    elif command == "3":
        contact = input("Кого знайти? ").strip().lower()

        if contact in contacts:
            print("Контакт знайдено")
        else:
            print("Контакт не знайдено")
    elif command == "4":
        contact = input("Кого видалити? ").strip().lower()

        if contact in contacts:
            contacts.remove(contact)
            print("Контакт видалено")
        else:
            print("Контакт не знайдено")
    elif command == "0":
        print("Контакти закрито")
    else:
        print("Невідома команда")
```

## Вправа 21. Черга клієнтів

Інструкція: програма має працювати до команди `0`. Команда `1` додає клієнта в кінець черги, команда `2` обслуговує першого клієнта через `pop(0)`, команда `3` показує чергу.

Приклад вводу/виводу:

```text
Ввід:
1
Анна
1
Богдан
2
3
0

Вивід:
Клієнта додано
Клієнта додано
Обслуговуємо: анна
['богдан']
Чергу закрито
```

Рішення:

```python
queue = []
command = ""

while command != "0":
    print("1 - додати клієнта")
    print("2 - обслужити першого")
    print("3 - показати чергу")
    print("0 - вихід")

    command = input("Ваш вибір: ").strip()

    if command == "1":
        client = input("Ім'я клієнта: ").strip().lower()

        if client:
            queue.append(client)
            print("Клієнта додано")
        else:
            print("Ім'я порожнє")
    elif command == "2":
        if len(queue) > 0:
            client = queue.pop(0)
            print("Обслуговуємо:", client)
        else:
            print("Черга порожня")
    elif command == "3":
        print(queue)
    elif command == "0":
        print("Чергу закрито")
    else:
        print("Невідома команда")
```
