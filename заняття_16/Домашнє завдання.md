## Обов'язкове завдання. Міні-додаток "Мої задачі"

Створіть Streamlit-додаток для списку задач.

Дані однієї задачі мають зберігатися як словник:

```python
task = {
    "title": "Повторити JSON",
    "priority": "важлива",
    "status": "new"
}
```

Усі задачі мають зберігатися як список словників у файлі `tasks.json`.

## Крок 1. Створіть базовий файл

Створіть файл `app.py`.

Додайте імпорти:

```python
import csv
import json
import os

import streamlit as st
```

Додайте константи:

```python
JSON_FILE = "tasks.json"
CSV_FILE = "tasks.csv"
FIELDS = ["title", "priority", "status"]
```

## Крок 2. Функція завантаження задач

Створіть функцію `load_tasks()`.

Вона має:

- якщо файлу `tasks.json` немає, повертати порожній список;
- якщо файл є, читати список задач з JSON;
- якщо JSON-файл пошкоджений, повертати порожній список.

Підказка:

```python
def load_tasks():
    if not os.path.exists(JSON_FILE):
        return []

    with open(JSON_FILE, "r", encoding="utf-8") as file:
        return json.load(file)
```

## Крок 3. Функція збереження задач

Створіть функцію `save_tasks(tasks)`, яка записує список задач у `tasks.json`.

Використайте:

```python
json.dump(tasks, file, ensure_ascii=False, indent=2)
```

Після збереження файл має бути читабельним і з українським текстом без дивних символів.

## Крок 4. Форма додавання задачі

## Крок 8. Експорт у CSV

Створіть функцію `export_tasks_to_csv(tasks)`.

Вона має створювати файл `tasks.csv` з колонками:

- `title`;
- `priority`;
- `status`.

Підказка:

```python
def export_tasks_to_csv(tasks):
    with open(CSV_FILE, "w", encoding="utf-8", newline="") as file:
        writer = csv.DictWriter(file, fieldnames=FIELDS)
        writer.writeheader()
        writer.writerows(tasks)
```

Додайте у Streamlit кнопку `Експортувати в CSV`.

Після натискання:

- створіть або оновіть файл `tasks.csv`;
- покажіть повідомлення `Створено файл tasks.csv`.
