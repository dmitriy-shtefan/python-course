# Завдання

- Заняття: 12
- Тема: Файли `.txt`, запис і збереження результатів

## Вправа 1. Перший запис у файл

Створіть файл `note.txt` і запишіть у нього один рядок тексту: `Моя перша нотатка`.

Після запуску програми відкрийте файл і перевірте, що текст зберігся.

Приклад вмісту файлу `note.txt`:

```text
Моя перша нотатка
```

## Вправа 2. Запис імені користувача

Попросіть користувача ввести ім'я і запишіть його у файл `user.txt`.

Приклад:

- Вхідні дані: `Оля`
- Вміст файлу `user.txt`:

```text
Оля
```

## Вправа 3. Запис привітання

Попросіть користувача ввести ім'я. Створіть текст привітання і запишіть його у файл `greeting.txt`.

Приклад:

- Вхідні дані: `Максим`
- Вміст файлу `greeting.txt`:

```text
Привіт, Максим!
```

## Вправа 4. Запис кількох рядків

Запишіть у файл `profile.txt` три рядки:

- ім'я;
- місто;
- улюблену мову програмування.

Кожен пункт має бути з нового рядка.

Приклад вмісту файлу:

```text
Ім'я: Ірина
Місто: Київ
Мова: Python
```

## Вправа 5. Символ нового рядка

Створіть програму, яка записує у файл `lines.txt` три окремі рядки за допомогою `\n`.

Приклад вмісту файлу:

```text

```

## Вправа 6. Режим `w` перезаписує файл

Створіть програму, яка двічі відкриває файл `result.txt` у режимі `w`.

Перший раз запишіть `Перший текст`, другий раз запишіть `Другий текст`.

Перевірте, який текст залишився у файлі після запуску.

Очікуваний вміст файлу:

```text
Другий текст
```

## Вправа 7. Режим `a` додає в кінець

Створіть програму, яка відкриває файл `log.txt` у режимі `a` і додає рядок `Програма запущена`.

Запустіть програму кілька разів і перевірте файл.

Приклад вмісту файлу після трьох запусків:

```text
Програма запущена
Програма запущена
Програма запущена
```

## Вправа 8. Додавання нотатки

## Вправа 25. Для сильнішого студента: експорт результатів гри

Приклад:

```text

```

Приклад вмісту файлу після кількох ігор:

