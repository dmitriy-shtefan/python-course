# Домашнє завдання 21. Публікація персонального проєкту на GitHub

**Дата заняття:** 20.07.2026 (понеділок)  
**Тема:** Персональний Streamlit-проєкт

## Мета

Зберегти код персонального проєкту в GitHub-репозиторії та підготувати його для подальшої роботи.

## Завдання

1. Створіть на GitHub новий публічний репозиторій для персонального проєкту.
2. Додайте до репозиторію актуальний код проєкту, зокрема файл `app.py` та інші файли, потрібні для його запуску.
3. Додайте файл `README.md`, у якому вкажіть:
   - назву проєкту;
   - короткий опис;
   - інструкцію для запуску.
4. Перевірте, що всі файли успішно завантажені та відкриваються на GitHub.

Не додавайте до репозиторію паролі, токени, ключі API та інші приватні дані.
