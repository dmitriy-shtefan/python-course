| Команда | Файл | Призначення |

## `st.Page()`

Створює об'єкт сторінки для багатосторінкового Streamlit-застосунку. Сторінку
можна побудувати на основі Python-функції або окремого Python-файлу.

Приклад із `app.py`:

```python
st.Page(
    show_about_page,
    title="Про мене",
    icon="👤",
    default=True,
)
```

Використані аргументи:

- `show_about_page` — функція, яка формує вміст сторінки;
- `title` — назва сторінки в меню;
- `icon` — іконка біля назви;
- `default=True` — робить сторінку початковою.


## `st.navigation()`

Створює навігацію між сторінками застосунку. Команда приймає колекцію об'єктів
`st.Page` і повертає сторінку, яку вибрав користувач.

```python
page = st.navigation(
    {
        "": [st.Page(show_about_page, title="Про мене")],
        "📁 Мої Проєкти": [
            st.Page(show_contacts_page, title="Список контактів")
        ],
    },
    position="sidebar",
)
```

Словник групує сторінки за розділами меню. Аргумент `position="sidebar"`
розміщує навігацію в бічній панелі.

## `page.run()`

Запускає сторінку, повернену функцією `st.navigation()`. Без цього виклику
вибрана сторінка не буде відображена.

```python
page.run()
```

`page` — це об'єкт активної сторінки, а `run()` — його метод.

## `st.markdown()`

Виводить текст із Markdown-розміткою. Якщо передати
`unsafe_allow_html=True`, команда також обробляє HTML і CSS.

```python
st.markdown(
    "<p class='hero-role'>Junior Python Developer</p>",
    unsafe_allow_html=True,
)
```

Параметр `unsafe_allow_html=True` слід використовувати лише для довіреного
HTML, оскільки Streamlit перестає екранувати передану розмітку.

## `st.columns()`

Створює кілька колонок і повертає окремий об'єкт для кожної з них.

```python
photo_column, intro_column = st.columns(
    [1, 3],
    vertical_alignment="center",
)
```

Список `[1, 3]` задає пропорції ширини: друга колонка втричі ширша за першу.
Аргумент `vertical_alignment="center"` вирівнює вміст колонок по вертикальному
центру. Для розміщення елементів усередині колонки використовується `with`:

```python
with photo_column:
    st.image("assets/profile-avatar.jpeg")
```

## `st.image()`

Виводить зображення з локального шляху, URL, масиву байтів або іншого
підтримуваного джерела.

```python
st.image(str(AVATAR_PATH), width=200)
```

У цьому прикладі `str(AVATAR_PATH)` задає шлях до фотографії, а `width=200` —
ширину зображення в пікселях.

## `st.container()`

Створює контейнер для логічного групування кількох елементів інтерфейсу.

```python
with st.container(border=True):
    st.subheader("Список контактів")
    st.write("Застосунок для збереження контактів.")
```

Аргумент `border=True` додає видиму рамку. Контекстний менеджер `with`
визначає, які наступні елементи належать контейнеру.
